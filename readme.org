** About
A permissively licensed modern *Fortran* implementation of Gauss–Jacobi quadrature:
nodes and weights on =[-1, 1]= for weight =(1-x)^α (1+x)^β= (α,β > −1). Multiple
algorithms, auto method selection, Coarray Fortran, and C/Python bindings.

** Quick install

#+begin_src bash
micromamba create -f environment.yml
micromamba activate gaussjacquad
fpm build --flag "-fcoarray=single"
fpm test  --flag "-fcoarray=single"
fpm run --flag "-fcoarray=single" gjp_quad -- 32 0.0 0.0 auto
#+end_src

Preferred library entry:

#+begin_src fortran
use GaussJacobiQuad, only: gauss_jacobi_rule
call gauss_jacobi_rule(npts, alpha, beta, x, wts)           ! auto
call gauss_jacobi_rule(npts, alpha, beta, x, wts, "glr")  ! forced
#+end_src

Methods: =auto= (picks =*_caf= when multi-image), =rec=/=rec_caf=, =gw=,
=algo665=/=algo665_dc=/=algo665_dc_caf=, =sturm=/=sturm_caf=, =glr=/=glr_caf=,
=bogaert=/=bogaert_caf= (Legendre only, =n≥21=). Details:
[[file:docs/orgmode/explanation/methods.org][methods]] · [[file:docs/orgmode/reference/method-names.org][name list]].

** Install from released packages

*** Rust (crates.io)

#+begin_src toml
# Cargo.toml
[dependencies]
gauss-jacobi-quad = "0.2"
#+end_src

Build =libgjp_cinterp= (meson) and set =GJP_CINTERP= to the =.so= path. See
=crates/gauss-jacobi-quad/README.md=.

#+begin_src rust
use gauss_jacobi_quad::{gauss_jacobi, Method};
let (x, w) = gauss_jacobi(32, 0.0, 0.0, Method::Auto)?;
#+end_src

*** Python (PyPI)

CPython *extension* wheel (ISO_C_BINDING =gauss_jacobi_rule_c=, multi-phase init,
free-threading ready). No =GJP_CINTERP= needed after install.

#+begin_src bash
pip install gauss-jacobi-quad
python -c "from gauss_jacobi_quad import gauss_jacobi; print(gauss_jacobi(32,0,0)[0][:3])"
#+end_src

Build from repo root (requires gfortran + OpenBLAS): =pip install .= or =python -m build=.
Trusted publishing: =.github/workflows/publish-pypi.yml= (OIDC + cibuildwheel, incl. =cp313t=).
