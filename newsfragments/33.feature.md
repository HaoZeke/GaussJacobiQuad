The installed C header `gjp_version.h` defines `GJP_VERSION_MAJOR`, `GJP_VERSION_MINOR`, `GJP_VERSION_PATCH`, `GJP_VERSION_STRING`, and `GJP_VERSION`. The Fortran module `gjp_version` exposes the same values and `gjp_get_version`, and is installed under `include/gaussjacobiquad/<compiler-id>-<compiler-version>/`.
