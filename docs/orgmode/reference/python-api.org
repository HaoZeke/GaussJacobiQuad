* Package =gauss-jacobi-quad= (CPython extension)

Primary distribution: meson-python wheel from the *repository root* (=pyproject.toml=).
Extension module =gauss_jacobi_quad._core= links Fortran + C ABI into one =.so=.

Features:

- Calls =gauss_jacobi_rule_c= (ISO_C_BINDING / same as =libgjp_cinterp=)
- Multi-phase init (PEP 489): =PyModuleDef_Init= + =Py_mod_exec=
- Heap exception type =GaussJacobiError= (module state)
- Packaging: Stable ABI (=cp39-abi3=) for GIL 3.9+; free-threaded wheel (=cp313t=)
  with =Py_MOD_GIL_NOT_USED= (cannot share abi3)
- No =GJP_CINTERP= required for the installed wheel
- Single-image methods only (no multi-image CAF from Python)

#+begin_src python
from gauss_jacobi_quad import gauss_jacobi, gauss_jacobi_scale, GaussJacobiError, GJP_OK, GJP_ERR_BOGAERT_AB

x, w = gauss_jacobi(n, alpha, beta)                 # method=None → auto
x, w = gauss_jacobi(n, alpha, beta, method="glr")
x, w = gauss_jacobi(n, alpha, beta, method="bogaert")
x, w = gauss_jacobi_scale(x, w, alpha, beta, a, b)  # [-1, 1] -> [a, b]
#+end_src

=gauss_jacobi_scale= maps nodes with =(b-a)/2 * x + (a+b)/2=, exactly =a=
at =x = -1= and exactly =b= at =x = 1=, and multiplies weights by
=((b-a)/2)**(alpha+beta+1)= so the rule integrates
=(b-t)**alpha * (t-a)**beta * f(t)= on =[a, b]=. Raises =GaussJacobiError=
on an invalid interval or when the scaled node or weight is non-finite
(=GJP_ERR_BOUNDS=). A weight factor that overflows on its own is not an
error when the product with the weight is finite.

- Returns: two =numpy.ndarray= of shape =(n,)= (nodes, weights).
- Raises: =GaussJacobiError= (message includes =status=N= matching C =GJP_ERR_*=).

CLI entry point: =gauss-jacobi-quad= (or =python -m= package CLI).

Sources: =python/src/gauss_jacobi_quad/=. Tests: =python/tests/=.
