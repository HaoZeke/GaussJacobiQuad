* Module =GaussJacobiQuad=

Public symbols:

- =gauss_jacobi_rule(npts, alpha, beta, x, wts [, method])= — *preferred*
- =gauss_jacobi(...)= — legacy required method string; forwards to the rule entry
- =gauss_jacobi_batch_caf= — multi-rule batch (CAF)
- =select_method_auto(npts, alpha, beta)= — deferred-length method string
  (CAF names when =num_images()>1=)
- =gauss_jacobi_scale(npts, alpha, beta, a, b, x, wts)= — in-place map of a
  =[-1, 1]= rule onto =[a, b]=

Nodes become =t = (b-a)/2 * x + (a+b)/2=, exactly =a= at =x = -1=
and exactly =b= at =x = 1=. Weights are multiplied by
=((b-a)/2)**(alpha+beta+1)= so the rule integrates
=(b-t)**alpha * (t-a)**beta * f(t)= on =[a, b]=
(the image of =(1-x)**alpha * (1+x)**beta=). Requires finite =a < b=.
A non-finite scaled node or weight is an error. A weight factor that
overflows on its own is not an error when the product with the weight
is finite. =-ffast-math= and =-ffinite-math-only= are unsupported,
because they delete the finite checks that reject that node or weight.

#+begin_src fortran
use GaussJacobiQuad, only: gauss_jacobi_rule, select_method_auto
use gjp_types, only: dp
real(dp) :: x(n), w(n)
call gauss_jacobi_rule(n, alpha, beta, x, w)              ! auto
call gauss_jacobi_rule(n, alpha, beta, x, w, "sturm")
call gauss_jacobi_rule(n, alpha, beta, x, w, "rec_caf")
call gauss_jacobi_rule(n, 0.0_dp, 0.0_dp, x, w, "bogaert_caf")
call gauss_jacobi_rule(n, alpha, beta, x, w, "glr_caf")
#+end_src

* Version

Module =gjp_version= is =src/gjp_version.f90=. Meson and fpm both compile it
(fpm has no configure_file). =scripts/set_version.sh= writes major.minor.patch
into =fpm.toml= (fpm rejects pre-release text). =gjp_version_string= and the
meson project version keep the full text, including a pre-release suffix.
The generated C header string stores that meson project version.

- =gjp_version_major=, =gjp_version_minor=, =gjp_version_patch= — each in 0..99
- =gjp_version_string=
- =gjp_version_compact= — =10000 * major + 100 * minor + patch= (tblite's packing)
- =gjp_get_version([major], [minor], [patch], [string])=
