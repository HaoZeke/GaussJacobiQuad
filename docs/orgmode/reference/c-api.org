* Version

=gjp_version.h= is generated by meson from the project version and installed
into the includedir, next to =GaussJacobiQuadCInterp.h=. A pre-release suffix
(=1.2.0rc1=, =1.2.0-rc.1=) and a missing patch (=1.2=, patch defaults to 0)
still set the numeric macros. The string keeps the original text.

- =GJP_VERSION_MAJOR=, =GJP_VERSION_MINOR=, =GJP_VERSION_PATCH= — each in 0..99
- =GJP_VERSION_STRING= — the project version string
- =GJP_VERSION= — =10000 * major + 100 * minor + patch= (tblite's packing).
  Configure fails above 99 so =1.100.0= cannot collide with =2.0.0=.

=gjp_version.mod= is installed to
=includedir/gaussjacobiquad/<compiler-id>-<compiler-version>/=.
=gjp_cinterp.pc= puts that directory and the header directory on =Cflags=
(=moduledir= names the module directory).


* Preferred entry

#+begin_src c
int gauss_jacobi_rule_c(int npts, double alpha, double beta,
                        double *x, double *wts, const char *method);
const char *gjp_status_string(int status);
#+end_src

- =method=: =NULL=, =""=, or ="auto"= → policy; else a method string (see [[file:method-names.org][method names]]).
- Returns =GJP_OK= (0) or =GJP_ERR_*= (does not abort on bogaert policy errors).

* Interval scaling

#+begin_src c
int gauss_jacobi_scale_c(int npts, double alpha, double beta,
                         double a, double b, double *x, double *wts);
#+end_src

In-place map from =[-1, 1]= to =[a, b]=. Nodes become
=t = (b-a)/2 * x + (a+b)/2=, exactly =a= at =x = -1= and exactly =b=
at =x = 1=. Weights are multiplied by
=((b-a)/2)**(alpha+beta+1)= so the rule integrates
=(b-t)**alpha * (t-a)**beta * f(t)= on =[a, b]=.
Returns =GJP_ERR_BOUNDS= for an invalid interval or a non-finite scaled
node or weight. A weight factor that overflows on its own is not an error
when the product with the weight is finite.
