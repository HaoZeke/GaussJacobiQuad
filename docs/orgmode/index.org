* GaussJacobiQuad

Permissively licensed *modern Fortran* Gauss–Jacobi quadrature: nodes and
weights on =[-1, 1]= for weight =(1-x)^α (1+x)^β= (α,β > −1). Multiple algorithms,
optional auto selection, Coarray Fortran paths, and C/Python surfaces.

* Features

- Preferred entry: =gauss_jacobi_rule= (optional method; blank / ="auto"= → policy;
  multi-image auto selects =*_caf=)
- Methods: =rec=, =gw=, =algo665=, =algo665_dc=, =sturm=, =glr=, =bogaert=, and
  =*_caf= variants (=rec_caf=, =sturm_caf=, =glr_caf=, =bogaert_caf=, =algo665_dc_caf=, …)
- CAF: root / eigenvalue / half-node ownership; multi-rule batch API
- C: =gauss_jacobi_rule_c= (single-image); Python: PyPI =gauss-jacobi-quad=
  (Stable ABI =cp39-abi3= + free-threaded =cp313t= wheels)
- SymPy accuracy harness for regime checks
- Bibliography managed via ookcite collection =GaussJacobiQuad= → =docs/refs.bib=

* Minimal example (Fortran)

#+begin_src fortran
use GaussJacobiQuad, only: gauss_jacobi_rule
use gjp_types, only: dp
integer, parameter :: n = 32
real(dp) :: x(n), w(n)
call gauss_jacobi_rule(n, 0.0_dp, 0.0_dp, x, w)          ! auto
call gauss_jacobi_rule(n, 0.5_dp, 0.5_dp, x, w, "glr")  ! forced
#+end_src
