* Coarray Fortran API (library)

** Scope
GaussJacobiQuad supports Coarray Fortran (CAF) for multi-image runs.

- *1-image* (portable): gfortran =-fcoarray=single=
- *Multi-image*: OpenCoarrays =libcaf_mpi= + *MPICH* (not OpenMPI with gfortran >=14)

** Methods

| Method string | Meaning |
|---------------|---------|
| =auto= (omit) | =select_method_auto= (single-image defaults) |
| =rec= | Serial recurrence Newton roots |
| =rec_caf= | Same math; roots owned across images |
| =gw= / =gw_caf= | Golub-Welsch + LAPACKE =dsteqr= (one rule is serial) |
| =algo665= / =algo665_caf= | Golub-Welsch + =imtqlx= QL (one rule is serial) |
| =algo665_dc= | Cuppen D&C + =imtqlx= leaves (same GW problem) |
| =algo665_dc_caf= | same; CAF hooks on merge (leaf-level structure) |
| =sturm= / =sturm_caf= | Sturm bisection + inv. iteration; CAF over eigenvalue index |
| =glr= / =glr_caf= | Prüfer phase + Newton; CAF over root index |
| =bogaert= | Legendre asymptotics (α=β=0, =n≥21=); single-image |

Aliases =gw_caf= / =algo665_caf= accept multi-image launch but do *not* split a
single eigensolve. Use the batch API for multi-image speedup on those methods.

** Single-rule API

#+begin_src fortran
use GaussJacobiQuad, only: gauss_jacobi_rule, select_method_auto
! Preferred: optional method; omit or "auto" uses select_method_auto
call gauss_jacobi_rule(npts, alpha, beta, x, wts)
call gauss_jacobi_rule(npts, alpha, beta, x, wts, "glr_caf")
#+end_src

** Multi-rule batch API (all methods)

#+begin_src fortran
use GaussJacobiQuad, only: gauss_jacobi_batch_caf
! alphas(nbatch), betas(nbatch), xs(npts,nbatch), wts(npts,nbatch)
call gauss_jacobi_batch_caf(npts, nbatch, alphas, betas, xs, wts, "gw")
! method: "rec", "gw", or "algo665"
#+end_src

Ownership: round-robin batch index =i= on image =mod(i-1, num_images())+1=.

** Build

#+begin_src bash
# 1-image
fpm build --flag "-fcoarray=single"
fpm test  --flag "-fcoarray=single"

# multi-image (OpenCoarrays + MPICH)
fpm build --flag "-fcoarray=lib" \
  --link-flag "-L$OC/lib -lcaf_mpi -L$MPICH/lib -lmpifort -lmpi"
cafrun -n 4 ./build/*/app/gjp_quad -- 64 0.5 0.5 rec_caf
#+end_src

Reproducible toolchain: see [[file:../docker/caf/README.md][docker/caf]].

** Timed driver

#+begin_src bash
# single-rule node partition (rec)
cafrun -n 4 ./build/*/app/gjp_bench_caf single rec_caf 6144 0.5 0.5 5 2

# multi-rule batch (rec|gw|algo665)
cafrun -n 4 ./build/*/app/gjp_bench_caf batch gw 192 48 0.5 0.0 5 2
#+end_src

** Correctness

=rec_caf= and batch paths match serial results within ~1e-12 (often exact 0 for
fixed cases). See =test/test_caf_rec.f90= and =test/test_caf_batch.f90=.

** Modules

| Module | Role |
|--------|------|
| =GaussJacobiQuad= | =gauss_jacobi_rule= / =gauss_jacobi=; re-exports batch |
| =gjp_auto= | =select_method_auto= policy |
| =gjp_rec= | =rec= / =rec_caf=, ownership helpers |
| =gjp_glr= | =glr= / =glr_caf= Prüfer + Newton |
| =gjp_bogaert= | Legendre asymptotics |
| =gjp_caf= | =gauss_jacobi_batch_caf= |
| =gjp_gw= | Golub-Welsch |
| =gjp_algo665= | Algorithm 655 + =imtqlx= |
| =gjp_lapack= | LAPACKE =dsteqr= wrapper |
